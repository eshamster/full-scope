# ズームモード 設計書

## 概要

グリッド全体を一つのキャンバスとして拡大・縮小・移動し、画像に集中して閲覧するためのモード。
編集モード (画像ごとの変形, `DESIGN_SCALE_AND_MOVE.md`) とは独立しており、マウスだけで完結する操作を基本とする。

## 操作仕様

| 操作 | 動作 |
|---|---|
| Shift+中クリック (= 左+中クリック) | ズームモード開始 (通常モードからのみ) |
| 中クリック / Esc | ズームモード終了 |
| ホイール奥 / 手前 | 拡大 / 縮小 (20% 刻み, 80%〜1000%, 初期値 100%) |
| マウス移動 | キャンバスをカーソルと逆方向へ移動 (1:1, 範囲制限なし) |
| 左クリック / → | 次のページ (表示枚数分) |
| 右クリック / ← | 前のページ (表示枚数分) |
| Q | ランダムジャンプ |
| Shift+B / B | ブックマーク切り替え / 次のブックマークへ |
| H / Shift+H | 履歴を戻る / 進む |

上記以外の操作 (グリッド変更・回転・削除・タグ・goto・フィルタ・編集モード遷移・コマンド一覧など) と、画像のドラッグ&ドロップはモード中は無効。

## 動作仕様

### キャンバスの変形
- `.grid` 要素に `translate(offset) scale(ratio)` を適用する。セル内の相対位置は変わらない
- 拡大・縮小は画面中央を基準とする (中央に映っている点が動かないよう、ずれも倍率に合わせて伸縮する)
- 移動範囲は制限しない。見失ってもページ送りでリセットされるため復帰は容易
  - 制限すると見たい部分を画面中央へ持ってこられないため
- ページ遷移 (caret の変化) 時・モード終了時に変形をリセットする。ブックマーク切り替えなど caret が変わらない操作ではリセットしない
- 拡大率の刻み幅・上下限は `zoom-mode-controller.svelte.ts` の定数で調整する
- 下限を 80% (100% から一段階の縮小) にしているのは縮小表示のためではなく、ページ送りのつもりで下スクロールしたときに無反応に見えないようにし、ズームモード中だと気付けるようにするため

### 無限移動 (Pointer Lock)
- モード開始時に `document.body.requestPointerLock()` を要求し、`movementX/Y` で移動量を受け取る。画面端でも止まらず、カーソルも非表示になる
- Pointer Lock はユーザー操作中に要求する必要があるため、中クリックの mousedown ハンドラ内で要求する
- Esc・フォーカス喪失などで Pointer Lock が外れた場合はズームモードも終了する
- Pointer Lock の解除で Esc を消費した直後に Esc の keydown が届いてもウィンドウを閉じないよう、終了後 500ms は Esc を無視する

### ページ (組) の区切り
- 組の区切りはモード開始時の先頭位置で決め、モード中は維持する (`ZoomGroup`)
  - 例. 2枚組で 1 枚目から開始: `1-2, 3-4, 5-6, ...` / 2 枚目から開始: `1, 2-3, 4-5, ...`
- 先頭・末尾の半端な組は半端なまま表示し、画像は先頭セルから詰める
- ページ送りは末尾の組から先頭の組へ (逆も) 折り返す
- ジャンプ系 (ランダム・ブックマーク・履歴) の移動先は組の先頭へ揃える
  - `ImageInfoManager.setCaretAligner` で揃える関数をモード中のみ設定する
  - 現在の組の中への移動は移動にならないため、ブックマーク・履歴では飛ばし、ランダムでは選び直す

### UI 表示
- 開始・終了時のトーストのみ。モード中の常時表示はしない (ページ番号は表示する)

## 構成

```
ZoomModeController (zoom-mode-controller.svelte.ts)  # モード状態・キャンバスの変形
    └ ZoomGroup (zoom-group.ts)                     # 組の区切り計算 (純粋ロジック)
Controller (controller.ts)                           # 'Zoom' モードのキー設定・ページ遷移時のリセット
ImageInfoManager                                     # caretAligner によるジャンプ先の揃え
+page.svelte                                         # Pointer Lock・マウス入力の振り分け・transform 適用
```
